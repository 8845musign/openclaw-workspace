1. **接続確認（まずここ）**  
   - Gmail読取テスト（例: 最新メール一覧が取れるか）

2. **OpenClawに配線**  
   - Gmailの自動通知までやるなら：  
     `openclaw webhooks gmail setup --account <あなたのGmail>`  
   - これで `hooks.gmail` 周りの設定が入る（推奨フロー）。

3. **Gateway再起動して反映**  
   - `openclaw gateway restart`

4. **Read-only運用を固定**  
   - OAuthスコープは `gmail.readonly` / `calendar.readonly` のみ  
   - 送信・作成系（gmail send / calendar create）は使わない設定にする

5. **実運用（朝サマリーなど）**  
   - heartbeat/cronで「未読メール要約」「今日の予定確認」を定期実行
