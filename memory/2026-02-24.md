## Auto Summary (cron)
- セッション運用について確認し、通常は長時間無操作でも自動で `/new` にはならない点を共有。
- `/new`（新しい会話を作成）と `/reset`（現在の会話を初期化）の違いを整理。
- 過去履歴の参照可否を確認し、SlackのDM履歴を遡れることを案内。
- 会話をMarkdownへまとめる機能はあるが、デフォルト自動保存ではないことを確認。
- 自動化の要望を受け、Gemini APIは不要であることを明確化。
- 毎日23:55（Asia/Tokyo）に日次要約を記録するcronジョブ「Daily Markdown Log」を作成。

## Manual Save (16:03 JST)
- `/restart` では要約の連続性が保証されない可能性を確認。
- ただし `/reset` は `session-memory` フック対象で、リセット前内容の保存に向いている点を確認。
- 「restart時hookできる？」への回答として、標準では `/new`・`/reset` 対応、`/restart` はカスタムhookが必要と整理。
- いま手動で本日の内容を memory ファイルへ保存実行。
