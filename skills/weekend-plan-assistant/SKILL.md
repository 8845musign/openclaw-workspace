# Weekend Plan Assistant

金曜夕方に実行し、今週末（土日）のおでかけ提案を3〜5件届けるスキル。

## ワークフロー

### 1. 天気予報を取得

```bash
curl -s "wttr.in/Tokyo?format=j1"
```

土曜・日曜の天気を確認し、以下を判定:
- 雨予報 → 屋内寄りの提案を優先
- 晴れ/曇り → 屋外イベントも積極的に含める
- 気温 → 極端に寒い/暑い場合は考慮

### 2. 都内イベント情報を検索

Web検索で以下のソースから今週末のイベントを収集する:

```
検索クエリ例:
- "東京 今週末 イベント"
- "東京 週末 おでかけ {YYYY年M月}"
- "東京 {今週末の日付} フェス OR マーケット OR 展覧会 OR ポップアップ"
```

**検索のコツ:**
- 日付を明示的に入れて鮮度を担保する
- 複数クエリで幅広くカバー（アート、フード、音楽、アウトドアなど）
- 公式サイトやイベントまとめサイトの情報を優先

### 3. カレンダー確認（ICS設定済みの場合）

ics-calendar-readerスキルが利用可能なら、土日の既存予定を確認して衝突を避ける。

### 4. 提案を組み立てる

以下の基準で3〜5件を選定:

**選定基準:**
- ジャンルの多様性（アート、グルメ、音楽、アウトドア、マーケットなど混ぜる）
- 天気との整合性
- 予算感（無料〜1,500円程度を中心に。高額なものは注記する）
- 既存予定との衝突なし
- 期間限定・今週末ならではのものを優先

**各提案のフォーマット:**

```
🎯 {提案タイトル}
📍 {場所}（最寄駅）
📅 {日時}
💰 {料金目安}
☁️ {天気との相性: ◎/○/△}
📝 {1〜2行の説明・おすすめポイント}
🔗 {URL}
```

### 5. 出力

提案の冒頭に天気サマリーを付け、その後に提案リストを出力。

**出力テンプレート:**

```
🐱 今週末のおでかけ提案にゃ〜

🌤 天気: 土曜 {天気/気温}、日曜 {天気/気温}

---

{提案1}

{提案2}

{提案3〜5}

---

気になるのあったら詳しく調べるにゃ〜 🐾
```

## Cron設定例

金曜18:00 JSTに実行:

```
openclaw cron add \
  --name weekend-plan \
  --schedule "0 18 * * 5" \
  --task "weekend-plan-assistantスキルを使って、今週末のおでかけ提案を作成してSlackに送って" \
  --channel slack:user:U08T8S3BBFX
```

## 注意事項

- 検索結果はリアルタイム性が重要。キャッシュや古い情報に注意する。
- イベント情報は公式ソースのURLを必ず添える。
- Slackでの出力時はmarkdownテーブルを使わず、上記のbullet形式を使う。
- 猫キャラの口調で出力する（SOUL.md / IDENTITY.md準拠）。
